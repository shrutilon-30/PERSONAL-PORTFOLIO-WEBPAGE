# 💼 Personal Portfolio Website

This is a fully responsive personal portfolio website designed to showcase my skills, projects, certificates, and contact information in a modern and professional way. The website features an attractive user interface with smooth animations, stylish fonts, full-screen sections, and a dark-themed design for better visual impact. It includes dedicated sections such as Home, About, Projects, Certificates, and Contact, along with social media links and GitHub project buttons. Each section is crafted to give a clean and organized look, making it easy for visitors to navigate and learn more about me.

## 🔧 Tools and Technologies Used

- **HTML5** – for structuring the web content  
- **CSS3** – for styling, layout, and advanced UI effects  
- **Responsive Design** – for perfect viewing on mobile, tablet, and desktop  
- **Flexbox & Grid** – for smooth and structured layouts  
- **Custom Fonts & Icons** – to enhance visual appeal  
- **Hover & Scroll Effects** – to give a modern interactive feel  

This portfolio is ideal for anyone looking to present themselves professionally online. It's simple to update and can be expanded with more sections like blog, resume, or testimonials in the future.
